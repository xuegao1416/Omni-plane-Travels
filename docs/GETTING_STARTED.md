# 世界漫游指南：快速开始

## 第一次游玩

1. 在大厅选择一枚世界晶体，打开世界详情。
2. 选择“选择并继续”，按向导填写角色信息和叙事视角。
3. 进入游戏后直接发送行动。左侧抽屉提供任务、事件、模块、资源和记忆入口。

大厅右上角的“指南”可以随时打开这份三步说明。空白晶体用于创建或导入自定义世界。

## 六类玩法模块

- **数值**：基础属性、派生属性和临时修正。
- **成长**：等级、经验、段位和成长奖励。
- **天赋与技能**：节点解锁、点数消耗、技能使用和冷却。
- **骰子检定**：属性、难度、优势/劣势和结果等级。
- **资源与生存**：资源、物品、配方、制作和时间成本。
- **经营**：资产、生产、员工、库存和周期结算。

模块通过统一的条件、消耗、奖励、效果和事件协议运行。没有图形化面板时，正文和普通面板仍可作为降级入口。

仓库中的 `public/examples/japanese-rpg-world.json` 是可直接导入的垂直样板，包含成长点数、分支天赋树、互斥路线、觉醒、技能熟练度和骰子检定。

## 记忆与向量检索

记忆系统会把剧情事实、系统状态、玩家/NPC 说法和玩家推测分层保存。推测会标记为“玩家推测”，不会自动覆盖已证实的世界事实；关系变化保留旧版本及有效轮次。

Embedding 是可选的增强能力。可以选择远程 API、应用内端侧模型或外部 OpenAI-compatible 本地服务；端侧模式会按需下载并初始化量化模型。没有启用、接口失败或模型不可用时，系统自动使用关键词召回，基础游玩不受影响。

## 平台能力边界

- Web 端使用浏览器存档和远程 API；无需安装本地模型即可游玩。
- Tauri 桌面端提供原生事件包管理、文件导入导出和原生 HTTP 能力。
- 设置中的免费体验入口只用于主对话，服务端为匿名设备签发不可由客户端重置的额度，每个身份最多成功完成三轮；上游失败不会消耗次数。
- 应用内端侧 Embedding 使用 WASM 推理，并限制批量大小以兼顾桌面与移动 WebView。Android 安装包可按[原生构建指南](native-build.md)生成。

## 扩展内容

事件包、工作流、自定义模块和创意工坊都是可选扩展。先完成一次基础旅程，再从大厅导航进入对应工具；世界包可以携带推荐的玩法内容，但安装前应检查兼容版本和依赖。
