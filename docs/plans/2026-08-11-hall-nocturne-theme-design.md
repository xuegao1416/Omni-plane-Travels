# 玄夜大厅主题设计

## 目标

玄夜主题下，大厅保持现有背景、五种比例布局和所有交互坐标不变，仅改变昼夜光照；水晶与圣火成为独立动态光源。其他入口页面继续使用固定的拂晓外观。

## 方案

- 继续使用每种比例现有的大厅背景图，不加载 AI 重绘图，保证建筑和底座逐像素对齐。
- 仅在 `html[data-theme="dark"] .entry-default-theme.entry-hall` 内对背景进行确定性的亮度、对比度和色温处理。
- 复用 `.entry-hall-shade` 叠加月夜环境光，不增加新布局节点。
- 放大并增强现有 `.entry-world-crystal__glow` 与 `.entry-hall-portal__firelight`，分别提供冷色晶体光和暖色圣火光。
- 大厅导航按钮改为玄夜玻璃材质；设置、事件中心、自定义模块和账号页面的固定主题边界不变。

## 验收

- 拂晓主题大厅外观不变。
- 玄夜主题呈现深夜，而不是简单灰暗滤镜。
- 背景构图、五种比例坐标、水晶与圣火位置不变。
- 水晶和圣火的光晕在玄夜中明显但不过曝。
