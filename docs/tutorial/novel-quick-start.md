# 小说拆解台：四步开始玩

在世界大厅打开「小说拆解台」。界面始终显示四个步骤和当前主操作，底部按钮会根据实际资料进度更新，不需要跟随截图寻找隐藏按钮。

1. **上传小说**：选择或拖入 TXT、EPUB，检查正文，再点「下一步：选择要拆的章节」。JSON 资料和恢复备份也可以直接导入。
2. **选章拆解**：新小说默认先试拆前 10 章，也可以自己填写起止章，或明确选择整本。选择只拆人物设定，或连原作故事一起拆。保存 AI 配置后，点底部「开始拆解第…章」；所选范围一起生效，其余章节不会调用 AI。
3. **人物与设定**：先看拆解效果。资料页直接显示当前任务范围，可以「再多拆 10 章」或重新选择章节。已有资料即可点「用当前资料创建世界」，不必等整本拆完。
4. **创建世界**：自由游玩填写名称即可创建。原作开局先选择已完成的故事段，再用底部主按钮依次「整理开局剧情」→「保存剧情版本并选用」→「创建世界，回大厅游玩」。

创建后在大厅选择世界，填写角色并开始冒险。详细开局说明：[自由游玩](novel-free-play.md)、[原作故事开局](novel-original-story.md)。

读取中断或失败时，已完成的资料会保留。点「暂停并保存」或「保存并关闭」，回来在「继续已有小说」中打开对应小说，界面会依据实际成果回到可继续的步骤。失败段可以单独重试，也可以先查看已有资料。

AI 读取与剧情整理会产生接口费用。重新归并、重新提取全部证据属于可选操作，集中放在「检索增强与重新处理」中。顶部「备份」下载原文与付费成果；换设备时导入该 JSON 即可恢复。
