# 小说拆解台：跟着图片开始玩

在世界大厅点「小说拆解台」，再点右上角「新手图解 · 跟着点」。教程一次只显示一步；点「带我打开这个页面」可以直接跳到当前要操作的位置，回来继续下一步。

选你想玩的内容：

- [在小说世界里自由玩](novel-free-play.md)：用小说的人物和设定，开始自己的故事。
- [扮演书中人物，按原作故事开局](novel-original-story.md)：让 AI 整理原作剧情，保存后选择人物和故事起点。

两种玩法都从上传小说讲到创建旅程。原作玩法必须用到的「主线剧情」直接展开；不用找隐藏折叠，也不用自己写剧情。红色编号和短箭头指向当前截图里的实际控件。

按钮不能点时，先看所在页面的缺项提示。想暂时停下来，点「保存并关闭」；回来在第一页选「继续已有资料」。换设备前先点「备份原文与付费成果」，再在新设备导入备份 JSON。

截图中的小说、人物和成果是教学示例。AI 接口地址、密钥与模型必须使用你自己的配置。
