# 《世界漫游指南》v3.0.0｜职业、技能与图形化战斗

这一次，不只是给聊天界面加几个按钮。

v3.0.0 把职业、天赋、自由技能、宠物、召唤物、道具与战斗真正接进同一套本地玩法内核。你仍然可以只安静地生活、经营、探索或谈恋爱；只有世界启用了对应模块，职业与战斗才会出现。

## 这次有什么

- 两套完整职业典藏：经典幻想与东方幻想，职业数量由典藏配置决定，每个职业均可拥有四阶职业树
- 每个职业都有机械有效的能力树、互斥专精与终极能力
- 最多 4v4 的独立卡片战场，支持自己、友方 NPC、宠物与召唤物编队
- 攻击、技能、道具、防御、逃跑，以及状态、冷却、治疗、暴击与资源消耗
- 敌方和自动友方使用本地策略 AI，战斗每回合不调用 API
- 普通、困难、炼狱三档战斗风险；炼狱死亡会封存旅程，但不会删除存档
- 战斗结束后才由主模型承接一次正文，AI 不能篡改已经结算的胜负与伤亡
- 断网、空回、刷新与重复点击都有恢复和幂等保护，不会重复扣道具或发奖励

## 它仍然是《世界漫游指南》

战斗不是所有故事的答案，也不会被强塞进六个官方世界。你可以把它挂进武侠、奇幻、末日或自己编织的世界，也可以完全不用它。

我想做的不是一套规定你必须如何游玩的系统，而是再交给你一组足够完整的工具：当故事真的走向冲突时，你可以亲手决定谁出战、使用什么能力、承担多大的风险；当战斗结束，世界会记住已经发生的一切，然后继续向前。
